# M0 compatibility spike

M0 is deliberately small. It exists to prove the platform assumptions on the
actual Kindle PW5 before M1 starts building the indexer.

## Pass criteria

On the target Kindle/KOReader build the compatibility probe must report PASS for:

1. `lua-ljsqlite3`
2. KOReader settings directory
3. `BookList` progress/status API
4. `ReadHistory`
5. `FileManagerBookInfo` metadata/cover API
6. `ReaderUI:showReader`
7. `DocumentRegistry`
8. live `FileManager ui.bookinfo`
9. SQLite create/write/read round-trip

If readable history exists, two additional probes should pass:

- reading state/progress for one real history item
- cached metadata for one real history item

The probe does not open or modify any book. Its temporary SQLite database is
deleted after the round-trip.
