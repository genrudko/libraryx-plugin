# LibraryX 0.4.4 Beta

## Русский

Добавлена отдельная кнопка LibraryX в верхнее меню KOReader во время чтения.

### Новое

- в ReaderUI LibraryX теперь регистрируется в верхнем меню;
- отдельная иконка LibraryX вставляется сразу после штатной кнопки файлового менеджера;
- тап по ней закрывает верхнее меню Reader и открывает LibraryX поверх текущей книги;
- текущая книга при этом не закрывается;
- на корневом экране LibraryX, открытом из режима чтения, появляется стрелка «назад», которая закрывает LibraryX и возвращает в ту же книгу;
- если из LibraryX выбрать другую книгу, используется штатный безопасный ReaderUI:showReader для переключения Reader → Reader.

### Совместимость

- filemanager-режим LibraryX не меняется: отдельная вкладка LibraryX и полный набор команд остаются как раньше;
- updater/Settings/сканирование не дублируются в Reader-меню — там только быстрый вход в библиотеку;
- lifecycle Exit/Restart из v0.4.2/v0.4.3 сохраняется.

### Проверки

- добавлен отдельный gate для reader-menu integration;
- проверяется регистрация ReaderUI, вставка top-level кнопки после filemanager, закрытие Reader menu перед открытием LibraryX и условная кнопка Back на корне библиотеки.

---

## English

Adds a dedicated LibraryX button to KOReader's top menu while reading.

### New

- LibraryX now registers with ReaderUI's top menu;
- a dedicated LibraryX icon is inserted immediately after KOReader's built-in file manager button;
- tapping it closes the Reader menu and opens LibraryX over the current book;
- the current book remains open underneath;
- LibraryX opened from Reader mode shows a Back arrow on its root screen, returning directly to the same reading session;
- choosing another book from LibraryX uses KOReader's safe ReaderUI:showReader Reader → Reader transition.

### Compatibility

- FileManager behavior is unchanged;
- Reader mode exposes only the quick LibraryX entry, not the full FileManager command set;
- Exit/Restart lifecycle fixes from v0.4.2/v0.4.3 remain intact.
