# LibraryX 0.2.0 Beta

## Русский

Первый функциональный релиз ветки 0.2: добавлена полноценная система настроек LibraryX.

### Новое

- раздел **Настройки** в меню LibraryX;
- **Список книг**:
  - плотность **Автоматически** или вручную **3–10 книг на экран**;
  - размер шрифта списка **80–120%**;
  - отдельно включаются/выключаются жанры, язык, номер книги в серии, формат/размер файла;
- **Превью книги**:
  - размер основного текста **70–130%**;
  - размер заголовка **80–130%**;
  - размер обложки **60–110%**;
  - отдельно включаются/выключаются жанры, метаданные и путь к файлу;
- выбор языка LibraryX: как в KOReader / Русский / English;
- сброс настроек интерфейса LibraryX к значениям по умолчанию;
- для новых установок плотность списка по умолчанию — **Автоматически**;
- существующее ручное значение 3–10 из предыдущих beta сохраняется через совместимость со старой настройкой;
- основной текст превью по умолчанию уменьшен до **90%**, чтобы на PW5 помещалось больше описания;
- главное меню теперь называется просто **LibraryX**, без отладочной пометки.

### Автоматическая плотность

В режиме **Автоматически** LibraryX использует реальную доступную высоту списка и расчёт KOReader CoverBrowser, но ограничивает результат диапазоном 3–10. Неполная последняя страница по-прежнему растягивает карточки на доступный viewport.

## English

First feature release in the 0.2 line: LibraryX now has a complete settings subsystem.

### New

- a dedicated **Settings** section in the LibraryX menu;
- **Book list**:
  - **Automatic** density or manual **3–10 books per screen**;
  - list font size **80–120%**;
  - independent toggles for genres, language, series number and file format/size;
- **Book preview**:
  - body text size **70–130%**;
  - title size **80–130%**;
  - cover size **60–110%**;
  - independent toggles for genres, metadata and file path;
- LibraryX language override: follow KOReader / Russian / English;
- reset LibraryX interface settings to defaults;
- new installations default to **Automatic** list density;
- existing manual 3–10 values from previous betas are preserved through legacy-setting compatibility;
- preview body text now defaults to **90%** to fit more description text on PW5;
- the top-level menu is now simply **LibraryX**, without the debug suffix.

### Automatic density

In **Automatic** mode LibraryX uses the real available list height and KOReader CoverBrowser's viewport-derived row calculation, clamped to 3–10. Short final pages still expand their rows to use the available viewport.
