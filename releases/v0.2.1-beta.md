# LibraryX 0.2.1 Beta

## Русский

Небольшой UX-фикс после добавления системы настроек в `v0.2.0-beta`.

### Исправлено

- пункт **Настройки** теперь отображается прямо на корневом экране **Библиотека**;
- настройки больше не спрятаны только в системном меню KOReader → LibraryX;
- корневой пункт открывает тот же единый экран настроек, поэтому оба входа используют одну конфигурацию и не расходятся.

Теперь путь выглядит очевидно:

`Библиотека → Настройки`

---

## English

Small UX fix following the settings subsystem introduced in `v0.2.0-beta`.

### Fixed

- **Settings** is now visible directly on the **Library** root screen;
- settings are no longer available only through the KOReader system menu → LibraryX;
- the root entry opens the same shared settings screen, so both entry points use one configuration source.

The direct path is now:

`Library → Settings`
