# LibraryX 0.1.1 Beta

## Русский

Исправление первого пользовательского дефекта после `v0.1.0-beta`.

### Исправлено

- адаптивное масштабирование карточек теперь применяется **сразу при первом открытии** автора или серии, даже если KOReader ещё впервые индексирует обложки/метаданные этих книг;
- фоновые обновления CoverBrowser после extraction больше не обходят LibraryX density profile;
- больше не требуется повторно входить в раздел или перелистывать страницу, чтобы получить правильный размер текста.

### Технически

KOReader CoverBrowser после первой фоновой индексации обновляет найденные строки напрямую через `item:update()`. Этот путь не проходит через полный `_updateItemsBuildUI()`, где LibraryX применял дополнительный адаптивный масштаб шрифта. Теперь фоновые row updates используют тот же geometry-derived font profile, что и обычный полный рендер страницы.

## English

Fixes the first user-reported issue after `v0.1.0-beta`.

### Fixed

- adaptive card scaling is now applied **on the very first open** of an author or series, even while KOReader is indexing cover/metadata information for those books for the first time;
- CoverBrowser background row refreshes no longer bypass the LibraryX density profile;
- reopening the section or changing pages is no longer required to get the correct text size.

### Technical note

After first-time background extraction, KOReader CoverBrowser refreshes discovered rows directly through `item:update()`. That path bypasses the full `_updateItemsBuildUI()` call where LibraryX previously applied its extra adaptive font scaling. Background row updates now use the same geometry-derived font profile as full page renders.
