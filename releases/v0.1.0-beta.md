# LibraryX 0.1.0 Beta

## Русский

Первый публичный beta-релиз LibraryX — индексированной библиотеки для KOReader в стиле AlReaderX.

### Что уже есть

- разделы **Все книги / Авторы / Серии / Названия / Папки**;
- поиск, сортировки, обратный порядок и быстрый переход **А–Я**;
- фильтры по языку, жанрам, датам, новизне файлов и формату;
- случайная книга;
- реальные обложки через KOReader CoverBrowser cache/extraction;
- карточки книг с названием, автором, серией, языком, жанрами, форматом и размером;
- адаптивная плотность **3–10 книг на экран**;
- неполная последняя страница использует всю доступную высоту экрана;
- отдельный экран информации о книге перед ReaderUI;
- long-press: **Читать / Удалить / Перейти / Избранное**;
- переход ко всем авторам книги, серии и каталогу;
- многометочное избранное:
  - К прочтению
  - Уже прочитано
  - Может быть позже…
  - Стоящая книга!
  - Мусор
  - Что-то непонятное
- возможность запускать KOReader сразу в LibraryX через штатное **Start with**;
- полная локализация интерфейса на русский и английский;
- английский fallback для остальных языков KOReader.

### Установка

Скачайте asset:

`libraryx-v0.1.0-beta.koplugin.zip`

Распакуйте каталог `libraryx.koplugin` в каталог плагинов KOReader.

На Kindle:

`/mnt/us/koreader/plugins/libraryx.koplugin`

После установки полностью перезапустите KOReader.

### Статус beta

Основное тестирование выполняется на Kindle Paperwhite 11 (PW5). В beta-линии возможны изменения UI, адаптивной плотности и совместимости с разными версиями KOReader.

## English

First public beta release of LibraryX — an indexed AlReaderX-inspired library frontend for KOReader.

### Included

- **All books / Authors / Series / Titles / Folders**;
- search, sorting, reverse order and fast **A–Z** navigation;
- filters by language, genres, dates, file novelty and format;
- random book;
- real covers using KOReader CoverBrowser cache/extraction;
- book cards with title, author, series, language, genres, format and size;
- adaptive **3–10 books per screen** density;
- short final pages use the full available viewport height;
- dedicated book-details screen before ReaderUI;
- long-press actions: **Read / Delete / Go to / Favorites**;
- navigation to every author, series and catalog;
- multi-label Favorites:
  - To read
  - Already read
  - Maybe later…
  - Worth reading!
  - Trash
  - Something unclear
- native **Start with LibraryX** integration;
- complete Russian and English UI localization;
- English fallback for other KOReader interface languages.

### Installation

Download:

`libraryx-v0.1.0-beta.koplugin.zip`

Extract the `libraryx.koplugin` directory into KOReader's plugin directory.

On Kindle:

`/mnt/us/koreader/plugins/libraryx.koplugin`

Restart KOReader completely after installation.

### Beta status

Primary testing is currently performed on Kindle Paperwhite 11 (PW5). UI, adaptive density and compatibility details may still change during the beta series.
