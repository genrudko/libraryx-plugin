# LibraryX 0.4.0 Beta

## Русский

Большое обновление интерфейса LibraryX: переработаны настройки, добавлены иконки, отдельная вкладка LibraryX в верхнем меню KOReader и встроенный updater.

### Интерфейс

- на главном экране Библиотеки появились иконки у основных разделов;
- настройки теперь разбиты на понятные разделы с иконками: Библиотека, Список книг, Превью, Навигация, Сканирование и индекс, Обновления, Язык, О программе;
- LibraryX получил собственную вкладку в штатном верхнем меню KOReader, аналогично Bookshelf;
- вкладка содержит быстрый доступ к библиотеке, избранному, папке библиотеки, сканированию, настройкам, обновлениям и информации о версии.

### Новые настройки

- показывать или скрывать навигацию А–Я / A–Z;
- сканировать библиотеку при открытии LibraryX;
- запуск обычного и полного пересканирования прямо из настроек;
- канал обновлений Beta или Stable;
- фоновые уведомления о доступной новой версии.

### Обновления

- ручная проверка GitHub Releases;
- отображение release notes перед установкой;
- загрузка готового .koplugin.zip из GitHub Release;
- установка поверх текущего LibraryX через штатный ffi/archiver KOReader;
- после установки предлагается перезапустить KOReader;
- автоматическая проверка выполняется в фоне не чаще одного раза в 6 часов и только уведомляет — установка всегда требует действия пользователя.

### Совместимость

- сохранены все возможности v0.3.0-beta: адаптивные карточки, Favorites, preview книги, RU/EN, Start with LibraryX и нативное верхнее меню KOReader;
- старые значения настроек сохраняются.

## English

Major LibraryX UI update: redesigned settings, icons, a dedicated LibraryX tab in KOReader's native top menu, and a built-in updater.

### Interface

- the Library home screen now has icons for its main destinations;
- settings are grouped into iconized sections: Library, Book list, Book preview, Navigation, Scanning and index, Updates, Language, About;
- LibraryX now has its own tab in KOReader's native top menu, similar to Bookshelf;
- the tab provides quick access to the library, Favorites, library folder, scanning, settings, updates and version information.

### New settings

- show or hide A–Z / А–Я navigation;
- scan the library when LibraryX opens;
- normal and full rescan actions directly from Settings;
- Beta or Stable update channel;
- background notifications when a newer version is available.

### Updates

- manual GitHub Releases check;
- release notes shown before installation;
- download the ready-made .koplugin.zip from the GitHub Release;
- install over the running LibraryX directory using KOReader's ffi/archiver;
- offer to restart KOReader after installation;
- background checks run no more than once every 6 hours and only notify; installation always requires user action.

### Compatibility

- all v0.3.0-beta features remain: adaptive cards, Favorites, book preview, RU/EN, Start with LibraryX and native KOReader top-menu access;
- existing settings are preserved.
